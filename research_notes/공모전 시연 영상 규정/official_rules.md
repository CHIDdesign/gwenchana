# 2026 현대자동차그룹 차량용 앱 개발 공모전 (Pleos) 공식 규정 중 시연 영상·숏폼·제출물

주의: 아래 공식 사이트 본문은 WebFetch(요약 모델)를 거쳐 받았다. 따로 표시한 곳 외 인용구는 도구가 돌려준 원문 인용이다. 공지 6번은 도구가 125자 제한으로 요약만 줬다(원문 직접 확인 권장). 사이트 날짜: 2026 판(접수 2026.10.21~11.15). 2025 판은 찾지 않음.
공식 사이트: https://appdevchallenge.auto-hmg.io/

## 1. 시연 영상 (필수 여부, 길이·해상도·형식·업로드, 내용 조건)

### Takeaway
시연 영상은 **선택 제출물이며 제출하면 가산점**이다. 목업·프로토타입·화면 녹화 모두 인정. 분량 제한 없음. 해상도·파일 형식·크기·업로드 방식·자막/언어 규정은 공식 자료에서 찾지 못함.

### Cited Findings
- 시연 영상은 선택, "목업 · 프로토타입 · 화면 녹화 인정." — [제출 가이드](https://appdevchallenge.auto-hmg.io/guide/submission)
- "1차 접수 시 시연 영상, GitHub 저장소, APK 등을 함께 제출하면 단계별 가산점을 부여합니다." — [심사·시상](https://appdevchallenge.auto-hmg.io/guide/judging-awards), [FAQ](https://appdevchallenge.auto-hmg.io/faq)
- FAQ: "개발 산출물(프로토타입 시연 영상, 소스 코드와 APK를 포함한 GitHub 저장소 링크)은 선택 제출물로 제출 시 가산점을 부여합니다." — [FAQ](https://appdevchallenge.auto-hmg.io/faq)
- 모집 공고: "시연 영상 · GitHub 저장소(소스 코드 및 APK 포함) 등 개발 산출물 — 선택", "목업, 프로토타입, 화면 녹화 모두 인정, 함께 제출하면 가산점" — [모집 공고](https://appdevchallenge.auto-hmg.io/notice/c0a1a000-2026-4923-8000-000000000001)

### Inferences
- "목업도 인정"이므로 에뮬레이터 실행이 영상의 필수 조건은 아니다. 다만 영상에 대한 구체 조건(출연자, 편집·합성, 내레이션)을 따로 정한 문구는 없어서 허용/금지 어느 쪽도 단정할 수 없다.

### Gaps
- 해상도, 파일 형식, 파일 크기, 최소 길이: 공식 자료에서 찾지 못함 (최대 길이는 "분량 제한 없음").
- 업로드 방식(YouTube 일부공개/Drive 등)과 접수양식에 링크로 적는지 여부: 공식 자료에서 찾지 못함. (숏폼 링크는 접수양식에 적는다고 명시됨, 시연 영상은 명시 없음.)
- 언어·자막 요건, 얼굴 노출·내레이션·편집 합성 허용 여부: 공식 자료에서 찾지 못함.
- 영상에 대한 가산점 배점 크기: "단계별 가산점"이라고만 하고 세부는 비공개.

## 6. 1차 제출 서류

### Cited Findings
- 필수는 접수양식 하나: "작성한 접수양식이 곧 기획서입니다." / "접수양식(기획서)만으로 지원할 수 있습니다." — [FAQ](https://appdevchallenge.auto-hmg.io/faq), [메인](https://appdevchallenge.auto-hmg.io/)
