# 실차 대응표 — 실제 차가 먼저, 게임은 대체본 (2026-11-02 갱신)

**원칙 (사용자 지시, 가장 중요):** 앱은 실제 차에서 Pleos SDK·안드로이드 표준 API로 얻을 수 있는 데이터만으로 동작해야 한다.
게임(BeamNG)은 그 데이터를 **같은 통로로 대신 만들어 주는 것**일 뿐이다. 실제 차에서 안 되는 기능을 핵심으로 만들지 않는다.
게임만 아는 값(시뮬레이터 정답)은 **앱에 보내지 않는다**. `game/bridge/runs/*.jsonl` 정답지에만 남기고 맞았는지는 PC에서 채점한다 (사용자 결정, 2026-11-02).

## 운영국 회신 요약 (2026-11-04·05·11)
- 자료는 Pleos Playground 공개 문서가 전부. 별도 신청·승인·자료 전달 없음. Connect SDK·NaviHelper는 공개 문서의 API만 제공.
- Android 표준 API는 Normal·Dangerous 권한까지 사용 가능, signature·privileged 불가. 이 기준이 개별 API나 차량 데이터의 실제 제공을 보장하지는 않음.
- 에뮬레이터 개발·시험은 승인 불필요, 권한 승인 전에도 소스·영상·APK 제출 가능.
- 문서에 없는 기능은 기획서에 **향후 계획**으로 적을 것. ADAS SDK 사용 불가. TTS 401·센서·카메라·초음파·CODA API의 개별 답은 아직 없음.
- 이 앱 권한 분류(Claude 판단): 가속도·자이로 센서 = 권한 불필요, CAMERA·RECORD_AUDIO·READ_PHONE_STATE·POST_NOTIFICATIONS·CAR_SPEED = Dangerous(사용자 허용), CAR_POWERTRAIN·FOREGROUND_SERVICE·RECEIVE_BOOT_COMPLETED = Normal, Pleos `pleos.car.permission.*` = 문서 안내대로 선언. **SYSTEM_ALERT_WINDOW는 signature|appop 계열 특수 접근**이라 기준에 애매함 → 없으면 전체 화면 알림으로 대신 띄우는 경로가 이미 있음(`CarService.kt:95`). **Pleos 프로필 서비스(`ACCESS_PROFILE_SERVICE`)는 signature|privileged라 불가** → 차 프로필 연동은 향후 계획.

## 게임 연동일 때만 다른 것 (2026-11-02)
- 기준: `CarService.game.connected` (PC 브리지 보조 통로 연결 여부).
- 보조 통로 항목은 `SIDE_KEYS`뿐: 합성 에어백, 제한속도, 시동(실차 SDK 값의 대체), `gamePos`·`mapVersion`(내비 배경).
- 사고 사진을 Camera2 대신 `/cam/latest.jpg`에서 받음. 게임 지도 내비를 엶. 나머지 판단 코드는 실차와 같다.
- 앱은 브리지를 2초마다 다시 찾음 → 브리지를 켜면 자동 연동.
