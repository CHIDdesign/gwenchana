# 현대차그룹 폰 앱 조사 — 우리 기능을 어디에 넣을까 (2026-10-30)

조사: 서브에이전트(웹 검색 위주). 한국 앱 화면(탭·색)과 Pleos 개발 문서 목차는 직접 확인 못 함 → 미확인 표시.

## 결론
**세 번째 독립 폰 앱**(사용자 생각과 같음). 현대차 공식 앱 안에 외부 팀이 기능을 넣는 공개 통로(SDK·미니앱·API)를 찾지 못했다(없을 가능성이 높다는 추정, 확정 아님). 기획서에는 "실제 서비스라면 현대차 공식 앱(마이현대) 안의 기능 + 같은 계정 자동 동기화"를 완성된 모습으로 적는다.

## 현대차그룹 폰 앱 (한국)
- **마이현대(myHyundai)**: 블루멤버스·마이카스토리·차량관리 등을 한 앱으로 통합했다는 기사 — [dailian](https://www.dailian.co.kr/news/view/1033887/). 출시 시점 미확인
- **블루링크(Bluelink)**: 원격 시동·공조, 주차 위치, 문 잠금, 목적지 보내기, 상담원 연결, **SOS 버튼(사고 처리·구난)**, 도난 경보 — [현대 공식](https://www.hyundai.com/kr/ko/digital-customer-support/app/myhyundai/bluelink)
  - 에어백 전개 자동 통보: 설명은 있으나 찾은 문구는 미국 기준, 한국 범위 미확인 — [오너스매뉴얼](https://ownersmanual.hyundai.com/ivi/STD_GEN5W/AVNT/KOR/Korean/009_BlueLink_service.html)
  - 사고 때는 상담센터가 112·119·보험사와 연계하는 방식. **단계별 행동 안내·사실 기록 기능은 찾지 못함** → 우리 앱과 겹치지 않고 보완 관계("블루링크 SOS와 함께 쓰는 증인")
- **기아 커넥트 / 제네시스 커넥티드**: 브랜드별 별도 운영(2023년 기사) — [smarttoday](https://www.smarttoday.co.kr/ko-kr/articles/31442)
- **현대 디지털 키**: 마이현대로 합쳐지는 흐름(상세 미확인)
- 해외: 2025-12-04 유럽에서 Bluelink + myHyundai 3.0을 합친 새 myHyundai 앱 발표 — [hyundai.news](https://www.hyundai.news/eu/articles/press-releases/hyundai-connected-mobility-launches-myhyundai-app.html). 한국 일정 미확인
- **Pleos·42dot 폰 앱**: 찾지 못함. 대신 **Pleos App Market은 폰 브라우저로 차 화면 QR을 찍어 Pleos 계정 로그인 → 차량 프로필과 계정 연동** — [오너스매뉴얼](https://ownersmanual.hyundai.com/ivi/Connect-S/AVNT/KOR/Korean/007_Vehicleconvenience_8.html)
- 블루링크·마이현대 계정과 차 내비 계정이 같은지: 공식 근거 못 찾음(미확인)

## 디자인
한국 앱의 탭 구조·색은 확인 못 함(미확인). 해외판은 "재설계된 화면에 서비스 예약·정비 이력·위젯" 정도. → 한국 마이현대 앱을 폰에 설치해 직접 보는 것을 권함.

## Pleos 폰 쪽 연동
- Pleos Playground(2025-03-28 공개): AAOS SDK, 디자인 가이드, API 문서, 샘플, 에뮬레이터. 행사에서 "모바일 SDK"가 언급되나 구성요소인지 불명확, 푸시 언급 없음 — [newswire](https://www.newswire.co.kr/newsRead.php?no=1008337)
- 문서는 `document.pleos.ai`로 이동(자바스크립트 페이지라 목차 못 읽음). 폰↔차 메시지·계정 연동 API는 미확인
- Pleos 프로필 서비스는 signature 권한 → 일반 앱이 못 씀(예전 세션 확인)

## 운영국에 물어볼 것
1. 폰 연동용 공식 계정·푸시 API가 있는지
2. 마이현대와 연계할 수 있는지
3. 차 앱이 외부 서버로 사고 데이터를 보내도 되는지(동의·보관 조건)
