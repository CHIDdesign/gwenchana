# Pleos 디자인 가이드 대조 (2026-11-07)

조사 방법: 공식 사이트 본문(document.pleos.ai, 같은 내용이 pleos-playground-docs.appmarket-int.umos.ai 사이트맵에 있음)과 로컬 PDF 15개를 읽음. 코드는 안 고침.
주의: 버튼·팝업·알림의 **크기·모서리·여백 숫자는 본문 글자가 아니라 그림(SVG)과 .fig 파일 안에만 있음** → 이번엔 못 읽음(아래 미확인).
사이트 개편: 옛 주소 `/docs/connect/guide/docs-design/...`는 목차 페이지만 열리고, 내용은 같은 경로로 그대로 읽힘. `/en/docs/pleos-only/...`는 새 구조.

## 3. 공식 아이콘·그림 자산과 얻는 법
- 공식 배포 파일은 **.fig 2개뿐**: 디스플레이 가이드 `https://document.pleos.ai/img/Pleos_Connect_display_guide_215.fig`, 디자인 자산 `https://document.pleos.ai/img/Pleos_Connect_design_assets_215.fig` (다운로드는 `Introduction/intro` 페이지 "Design Resources Download"). 이번엔 안 받음(44MB 지시).
- 디자인 자산 .fig 안에 아이콘 라이브러리가 있는지: **본문에는 안 적혀 있음.** 앱 아이콘 격자·마스킹 템플릿이 들어 있다고 `app-icon` 페이지가 말함. 아이콘 종류(Vehicle/System/Climate/Telltale) 설명 그림은 있으나 SVG 개별 다운로드 링크는 **없음**.
- 별도 .svg/.zip: 로딩 애니메이션(Loading.svg, 애니메이션 페이지에 링크)만 확인.
- 라이선스·재배포 조건: 페이지에 **명시 없음**. 푸터에 "© Hyundai Motor Group. All rights reserved." → 공개 저장소에 공식 아이콘/자산을 넣기 전 운영국 허락 확인 필요.
- 일러스트·3D 가이드: 공식 일러스트 세트는 없음. 3D는 glTF/Filament(공조·시트·핸들 등 차량 부품 제어용 예시). 우리 앱 3D(three.js, glb)와 방식이 다르지만 가이드 위반은 아님.

## 4. 블러·반투명·일러스트·애니메이션 허용 여부
- **블러/유리(glass)**: 금지 문구도 허용 문구도 없음. 가이드에 있는 반투명은 색 토큰의 알파값(5~50%)과 그림자뿐. → "유리 효과가 공식 스타일"이라는 근거는 없음. 쓰면 가이드 밖 → 쓰지 않는 쪽이 안전.
- **일러스트(정적 그림)**: 정보 전달에 필요한 최소한이면 허용. 차량 알림 구성에 "가이드 이미지"가 공식으로 들어 있음. 장식용은 피함.
- **애니메이션**: 목적은 "상태 설명". 주행 중에는 동영상·움직이는 이미지·자동 스크롤 금지, 자동 애니메이션·반복 전환 최소화. 정차/주행 규제 해제 상태에서는 가이드가 막지 않음. 우리 `animate = stopped`(주행 중 정지)는 방향이 맞고, 사고 후 안내가 정차 중에 일어나므로 문제 낮음. 단 판단 기준을 차량 신호(`CarUxRestrictions`)로 바꿔야 가이드와 일치.
- 사고 화면은 "사고 뒤 정차한 때만 연다"는 흐름이라 심사에서 "주행 중 UI" 항목과 충돌 가능성은 낮지만, 주행 중 배너(`Stage.BANNER`)가 규제 중에도 뜨는지는 확인 필요.

## 5. 미확인
- 버튼 크기(Large/Medium/Small 높이·폭), 팝업 폭, 시스템/차량 알림 크기·위치, 모서리 반경, 간격: 모두 SVG 그림(`basic_size.svg`, `pop_size.svg`, `noti_driving3/4.svg`)과 .fig 안. SVG는 글자가 도형으로 바뀌어 있어 텍스트 추출 실패.
- 상태바·GNB 높이, 안전 영역 40dp 외 수치 (layout 페이지에 없음, status-bar/gnb 페이지는 이번에 안 읽음).
- 아이콘이 .fig 안에 실제로 들어 있는지, 사용 라이선스.
- `components/` 나머지(tabs, switches, spinner 등)와 `Experiences/gleo-ai` 페이지는 로컬 PDF 글자만 확인, 사이트 본문은 안 읽음.
- `Introduction/theme`, `design-token`: 본문에 라이트/다크 사용 규칙 글자 없음(그림만).
- 본문 값 ↔ 실제 에뮬레이터 모양 차이(검정 버튼, 각진 모서리)가 가이드 갱신 때문인지 .fig 버전 차이(215)인지 확인 못 함.
