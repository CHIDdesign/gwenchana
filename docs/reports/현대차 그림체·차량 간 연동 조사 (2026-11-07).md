# 현대차 그림체 · 차량 간 연동 · 사고 대처 앱 조사 (2026-11-07)

조사 방식: 웹 검색과 페이지 읽기만 함(코드 안 바꿈). 검색 도구 요약이 얕아서 **원문 확인이 안 된 것은 "미확인"**으로 표시했다.
`document.pleos.ai`는 자바스크립트로 그려지는 페이지라 본문이 안 읽힘 → Connect SDK 문서 본문은 이번에 직접 못 봄.

  - 2015 HYUNDAI MOTORSTUDIO 브랜드 지침(iF 수상작 설명): https://ifdesign.com/en/winner-ranking/project/hyundai-motorstudio/152588 (일러스트 내용 미확인)

## B. 차량 간 연동

### 일반 Pleos Connect 앱이 얻을 수 있는 ID (확인된 범위)
| 항목 | 일반 앱 접근 | 근거 |

| 사용자 계정 ID/프로필 | 공개 Connect SDK에서 못 찾음(프로젝트 기록도 "일반 앱은 Pleos 프로필 못 읽음") | CLAUDE.md |

### 기존 제품은 상대를 어떻게 맞추나
- **프랑스 e-Constat Auto**: 두 운전자가 각자 폰에서 작성 → 상대 차량은 **상대 앱의 QR 스캔 또는 수동 입력** → 두 폰에 **SMS 보안 코드** 발송·입력 → 전자서명 → 두 보험사에 자동 전송. 서명 뒤 수정 불가. 대인 피해 없는 2대 사고만 대상. (보험사·비교 사이트 요약 기준, 공식 사이트 원문은 미확인)
  - https://www.assurland.com/assurance-auto/sinistres/constat-amiable/e-constat.html
  - https://www.jechange.fr/assurance/auto/e-constat
- Progressive/CMT, Tesla, EU eCall: 이번에 조사 못 함 → 미확인. (eCall은 알고 있는 범위로 "차 → 긴급센터 한 방향"이라 두 차 매칭 용도가 아님, 출처 미확인.)

### 권장 설계 (현실적인 안)
1. **기본 = 폰 중심 매칭.** 차 안 앱이 사고를 감지하면 사고 요약(시각, 위치, 충격 방향)을 서버에 올림. 차 앱은 상대 차를 직접 찾지 않는다(식별자가 없으므로).
2. **사고 화면에 일회용 QR + 6자리 코드 표시.** 상대 운전자가 자기 폰(또는 차 화면)에서 스캔/입력 → 서버가 두 기록을 하나의 "사고 방"으로 묶음. e-Constat과 같은 방식.
3. **자동 후보 추천(보조)**: 같은 시간(예: ±60초) + 같은 위치(예: 100m 안)에서 올라온 기록을 후보로만 보여 주고, **반드시 코드 확인 뒤에만 연결**(오연결 방지, 무관한 사람 위치 노출 방지). 숫자 기준은 제 추정값.
4. 합치는 것은 "사실 타임라인"만, 각자 기록은 각자 보관, 상대에게는 **본인이 고른 항목만** 공개. 과실 판정·비교 문구 없음.
5. 한 명만 앱이 있어도 동작해야 함(QR 대신 링크를 문자로 보내기).

### 한국 법 요건 (일반 원칙, 변호사 확인 필요)
- 상대에게 내 주행 기록을 주는 것은 개인정보 **제3자 제공** → 정보주체 동의, 알릴 것: 제공받는 자, 목적, 항목, 보유기간, 거부권·불이익(개인정보보호법 제17조). 받은 쪽은 목적 외 이용·재제공 금지(제19조). https://korea.legal/wiki/%ea%b0%9c%ec%9d%b8%ec%a0%95%eb%b3%b4-%eb%b3%b4%ed%98%b8%eb%b2%95-%ec%a0%9c17%ec%a1%b0/
- 위치는 **위치정보법 제19조**(개인위치정보 이용·제공)도 걸릴 수 있음. 동의 요건 세부와 "사고 상대방에게 제공" 예외 여부는 **미확인**. 원문: 국가법령정보센터.
- 설계 결론: (1) 연결 시점에 상대별 **별도 동의 화면**, (2) 공유 항목 체크, (3) 언제든 철회·삭제, (4) 보관기간 명시, (5) 서버 저장은 최소화·암호화. 지금 프로젝트는 "서버 인증 없음"이라 실제 연동 전에 인증이 필요(CLAUDE.md 기록).

## C. 단계별 사고 대처 안내 앱 사례
- 이번 검색으로 **"단계별 일러스트·애니메이션 사고 대처 화면"을 확인한 앱은 못 찾음**. 앱스토어 설명과 약관 문서만 나옴.
- 삼성화재: 앱에 사고접수·긴급출동 기능(2011년 기사 기준이라 현재 화면 미확인). 자동차보험 약관 PDF에 현장 대처 순서가 글로 있음: 정차·확인 → 부상자 구호 → 여러 각도 사진 → 안전한 곳으로 이동 → 목격자 확보 → 필요 시 경찰. 24시간 접수. https://www.samsungfire.com/publication/pdf/20071_0_20251116_file1.pdf , 앱: https://apps.apple.com/app/id409967827
- 현대해상 다이렉트: 고장출동/사고접수 기능. 2011년 기사에 상황별 대처요령 안내가 있었다고 함(현재 화면 미확인). https://apps.apple.com/app/id1265054195
- 해외: e-Constat은 항목별 입력 흐름(사진·약도·서명)이 단계형 화면. 그림 스타일은 미확인.
- 다음에 할 일: 위 앱을 에뮬레이터/폰에 직접 설치해 "사고 대처 요령" 화면을 캡처하는 것이 가장 정확함(사용자 몫).
