# 사고 유형별 촬영 가이드 조사 (2026-10-29)

웹 조사(에이전트, 사람 검토 전). 앱 원칙: 판사가 아니라 증인 — 과실 판단 없이 사실을 안전하게 남기는 안내만.

## 결론
- 사고 **종류별** 촬영 목록을 정한 공식 체크리스트(경찰청·도로교통공단·손해보험협회·보험사)는 **찾지 못함**.
- 공식 자료는 공통 원칙뿐:
  - 삼성화재 약관(2025): 여러 각도 촬영, 사고 위치 스프레이 표시, 목격자. 증거 확보 후 위험하면 차를 옮기고 엔진 끄기. 블랙박스 = "과실비율 입증자료" [S1]
  - 서울시설공단 FAQ(자동차전용도로): 정차 → 안전삼각대(주간 100m·야간 200m) → 도로 밖 대피 → 119 → 목격자 → **현장 촬영** → 112 (촬영은 대피·구호 뒤) [S2]
  - 미국 텍사스 보험국: 다른 차·번호판·손상, 도로 표지, 도로 각도, 부딪힌 물체 [S3]
- 종류별 세부는 주로 법률 칼럼·언론 → 앱에서는 "앱 제안"으로 표시해야 함.

## 종류별
| 사고 종류 | 필수 | 권장 | 남기는 사실 / 주의 |
|---|---|---|---|
| 고속도로 | 촬영보다 대피(비트박스: 비상등·트렁크·가드레일 밖·신고) [S4], "현장 기록보다 안전지대 이동" [S5, 2차사고 치사율 54.3%] | 가드레일 밖에서만 [S2 순서] | 도로·차 안 머무르지 말 것 [S6]. 무료 긴급견인 [S7]. 망원 구도는 출처 없음 |
| 시내 후방 추돌 | 양쪽 차 손상 위치·방향 [S8 블로그], 번호판, 멈춘 위치 전경 [S5][S9] | 바퀴 방향, 상대 블랙박스 여부 [S5][S10], 블랙박스 원본 보관 [S8] | 브레이크등·차간거리 촬영은 출처 없음 |
| 차로 변경 측면 접촉 | 차선 위 두 차 + 접촉 부위 [S9], 차량 위치·차선 표시 [S11] | 블랙박스 원본, 주변 차 영상 요청 [S11] | 차선 침범 정도는 옮기기 전 사진뿐 [S9] |
| 교차로(신호 쟁점) | 교차로 전체·신호등·정지선 함께 [S12][S13] | 각 운전자 쪽에서 본 신호 [S14], 20~30걸음 물러나 전체 [S15], 주변 CCTV 위치 [S16] | 신호 상태는 CCTV·블랙박스로, CCTV 보관 짧음 → 빨리 요청 [S16] |
| 주차장·후진 | 차량 위치, 파손 부위, 주차선과 거리, 주변 차 [S17] | 관리실·CCTV·목격자 [S17], 블랙박스 [S18] | 통로 폭은 출처 없음 |
| 단독(벽·시설물) | 부딪힌 물체 [S3] | 도로 상태, 가려진 표지판 [S19] | 시설물 신고 항목 출처 없음 |
| 보행자·자전거 | 119·응급조치 먼저 [S1][S2], 함부로 옮기지 않기 [S20] | 차량·노면 흔적 위주 | 얼굴 촬영 자제는 출처 없음(초상권 판례만 [S21]) |
| 정차 중 피해 | 먼저 정차(옮기면 뺑소니 오해) [S5] | 후방 추돌과 같음 | — |
| 개문 사고 | 문 열린 각도, 정차 위치, 충돌 지점, 도로 폭 [S22] | 블랙박스·CCTV | 블로그 1개뿐 |

공통: 걸으며 찍는 영상은 공식 권고 없음 → "앱 제안" 유지 [S5][S23]. 차 옮기기: 표시·사진 → 위험하면 이동 [S1], 도로교통법 제54조 [S24, 2차 출처 — 원문 대조 필요].
