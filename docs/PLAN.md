# 개발 계획 — Hey, Why not ask the Car?

작성 2026-10-29. 근거 자료는 기획서 "최종 아이디어 정리", 인수인계 문서 CLAUDE.md, 공모전 가이드다.
기능 범위는 기획서의 **"반드시 만들 것"** 목록이 기준이다. 이 문서는 그 목록을 어떻게 구현할지 정리한 것이다.

## 0. 확정된 결정
| 항목 | 결정 |
|---|---|
| 1차 목표(11/15) | 기획서 + 시연 영상 + GitHub(`apk/팀명_앱이름_release.apk`, README) |

## 1. 기획서 체크리스트 → 구현

| 기어 P, 에어백 감지 → 안내 시작 | 에어백 상승 에지 또는 주행 중 P로 전환 또는 사고 버튼 → `CrashTrigger` | 예정 |

여유가 있으면 할 것: 두 차 기록 교환, 인정기준 도표 번호 후보.

### 안내 분기 (사람 축 × 상황 축)
- 상황 축은 `(고속도로?, 정차(P)?, 야간?, 에어백?)`, 사람 축은 `(상세 | 간결 | 음성, 렌터카?, 동승자?)`이다.
- 안내 문구는 `assets/guides.json` 한 파일에 둔다. 코드는 조건에 맞는 단계 목록만 고른다.
- 공통 순서: 부상자가 있으면 119가 최우선이다. 고속도로면 대피를 먼저 하고, 시내 경미 사고면 촬영 체크리스트를 먼저 보여준다.
- 화면은 정차(P) 후에만 띄운다. 음성 모드는 TTS로만 안내한다.

### 테스트 모드 프로토콜 (1번 BeamNG 브리지와 맞출 약속)
- 앱이 클라이언트, PC가 서버다. 주소는 `10.0.2.2:8765`이고 10Hz로 줄마다 JSON 한 개를 보낸다.
  `{"t":1730000000.12,"speed":62.3,"steer":-4.5,"brake":true,"signal":"L","gear":"D","cruise":false,"airbag":false,"lat":37.5,"lon":127.0}`
- 클립은 `GET http://10.0.2.2:8766/clip/latest.mp4`로 받는다.
- 앱에는 실차가 주는 값만 보낸다. 게임 손상 정보는 정답지로만 쓴다.

## 3. 미확인
- Vehicle SDK의 지시등(TurnSignal)·기어·속도 API 시그니처 → 문서 조사 중
- NaviHelper로 도로 종류를 알 수 있는지
- `adb emu geo fix`가 Pleos 에뮬레이터의 FusedLocation에 반영되는지
- 영상 분석 시 상대 번호판·얼굴 같은 개인정보 처리(가림 기능)는 2순위
- 운영국 문의 항목은 기획서의 "운영국 문의" 목록을 따른다
