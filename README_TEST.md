# 직접 시험하는 방법

게임(BeamNG)에서 사고를 내면 에뮬레이터의 앱이 반응하는지 보는 방법입니다.

## 처음 한 번만

1. BeamNG를 켰다가 끕니다.
2. 다시 켜서 **옵션 > 프로토콜 > 기타 프로토콜**을 켭니다. 이 메뉴가 안 보이면 간단 메뉴(simple menu)를 먼저 끕니다.

## 시험하기

1. BeamNG를 켭니다. 실행기 창이 뜨면 맨 위 **실행**을 누르고, 게임에서 **자유 주행**으로 들어갑니다.
2. 프로젝트 폴더의 **`시작.cmd`** 를 더블클릭합니다. 에뮬레이터와 앱이 알아서 켜지니 1~2분 기다립니다. 에뮬레이터 창은 두 번째 모니터로 옮겨집니다. 이 검은 창은 닫지 마세요.
3. 검은 창의 표가 모두 `OK`가 될 때까지 기다립니다. `확인 필요`가 있으면 그 줄에 적힌 대로 합니다.
4. 처음이면 동의 화면이 나옵니다. 차 에뮬레이터에서는 **동의하고 시작**을 누르고, 휴대폰 에뮬레이터에서는 아무 운전자로나 로그인합니다.
5. 게임 오른쪽 아래 **ENGINE START STOP** 을 눌러 시동을 겁니다(이 차는 처음 누르면 전원만 켜지고, 위 화살표를 누르면 엔진이 걸립니다).
6. 위 화살표로 운전하다가 벽이나 다른 차에 세게 부딪힙니다. 아래 화살표를 계속 누르면 브레이크 뒤 후진이 되니, 차가 멈추면 손을 뗍니다.
7. 사고 안내의 비상등 단계에서는 게임에서 `/` 키로 비상등을 켜면 다음으로 넘어갑니다.

**게임 창은 최소화하지 마세요.** 최소화하면 사고 사진과 영상이 찍히지 않습니다.

`시작.cmd`는 OBS도 트레이로 켜서 카메라 6곳(블랙박스 앞·뒤, 서라운드 4)을 계속 녹화합니다. 게임 프레임이 약 20% 줄어요. 게임이 버벅이면 `시작.cmd` 대신 `python game\bridge\launcher.py --no-obs`로 켜세요(영상은 없음). 영상은 사고 기록 화면의 **카메라 영상 보기**에 있습니다.

## 이렇게 나오면 정상

| 언제 | 차 에뮬레이터 | 휴대폰 |
|---|---|---|
| 시작(시동 꺼짐) | 검은 화면 | 바탕화면 |
| 게임에서 시동 켬 | 시동 그림 약 9초 뒤 게임 지도 내비. 운전자는 오른쪽 위 동그라미를 눌러 바꿈 | 바탕화면 |
| 게임에서 R 또는 시동 끔 | 약 1초 안에 검은 화면 | 알림 닫힘 |
| 달리는 중 사고 | "안전한 곳에 차를 세우세요" | 사고 알림 |
| 차를 세움 | "다치셨나요?" 화면 | 알림을 누르면 안내가 열림 |
| 팝업에 답함 | 단계별 안내, 사고 재현, 사고 기록 | 같은 안내 |

후진을 넣었다 빼면 약 3초 동안 다른 화면이 보였다가 앱 화면으로 돌아옵니다.

## 다시 하기

게임에서 **R**을 누릅니다. 시동이 꺼지면서 차 화면이 검어지고, 사고 화면과 휴대폰 알림이 닫힙니다. 시동을 다시 걸면 내비로 돌아갑니다. 저장된 사고 기록은 남습니다.

## 끝내기

1. **`끝내기.cmd`** 를 더블클릭합니다.
2. BeamNG를 닫습니다.

SSD를 꺼내려면 Claude 앱, 이 폴더를 연 탐색기 창, 터미널도 모두 닫은 뒤 안전하게 제거를 누릅니다.

**시연 영상을 찍기 전**에는 끝내기로 끄고 새로 켜세요. 에뮬레이터를 몇 시간 켜 두면 멈출 때가 있습니다.

## 안 될 때

| 문제 | 해결 |
|---|---|
| 표에서 `게임`이 `확인 필요` | 차에 타고 있는지, 기타 프로토콜을 켰는지 확인 |
| 에뮬레이터가 안 움직임 | `시작.cmd`를 다시 실행 (멈춘 에뮬레이터를 다시 켭니다) |
| 내비가 안 보임 | 게임에서 R을 누르고 시동을 다시 걸기. 그래도 없으면 `시작.cmd`를 다시 실행 |
| 부딪혀도 사고 화면이 안 뜸 | 더 세게 부딪혀 보기. 살짝 스치면 사고로 안 잡힙니다 |
| 사고 사진이 없음 | 게임 창이 최소화됐는지 확인 |
| 카메라 영상 보기 버튼이 없음 | 사고 뒤 10초 넘게 기다렸는지, 상태표의 OBS 줄이 OK인지 확인 |
| 휴대폰 알림이 안 옴 | `시작.cmd` 상태표의 동기화 서버 줄과 휴대폰 로그인 계정 확인 |
| "주행 중 사용 불가" | 달리는 중에는 설정을 열 수 없습니다. 차를 세운 뒤 열기 |
| 게임 키보드가 안 먹힘 | Esc로 게임 메뉴를 열었다 닫기 |
| 게임이 튕김 | 게임 그래픽 설정을 낮추기 |

## 코드를 고친 뒤

프로젝트 폴더에서 빌드하고 `시작.cmd`를 다시 켭니다. 코드를 고치지 않았으면 필요 없습니다.

```bash
tools\run.cmd .\gradlew.bat :app:assembleDebug
```

## 실제 안드로이드 폰으로 하기

휴대폰 에뮬레이터를 안 켜서 PC가 조금 가벼워집니다. 이 방법은 아직 실제 폰으로 시험해 보지 않았습니다.

1. 폰과 PC를 같은 와이파이에 연결합니다.
2. 폰에서 USB 디버깅을 켜고 PC에 연결한 뒤, 프로젝트 폴더에서 앱을 설치합니다.

   ```bash
   <드라이브>:\askthecar-tools\sdk\platform-tools\adb.exe -d install -r -g phone\build\outputs\apk\debug\phone-debug.apk
   ```

3. `시작.cmd` 대신 **`시작-실제폰.cmd`** 를 켭니다. 방화벽을 물으면 허용합니다.
4. 검은 창에 나온 `http://...:8767` 주소를 폰 앱의 서버 주소 칸에 넣고, 아무 운전자로나 로그인합니다.
5. 폰을 바탕화면으로 나가 둡니다. 사고가 나면 알림이 옵니다.

## 사람 없이 자동으로 시험하기

평소 시험에는 필요 없습니다. 자동 시험이 도는 동안에는 프로그램이 게임 차를 움직입니다.

**준비:** Steam에서 BeamNG 속성 > 실행 옵션에 `-enablemcp`를 적고 게임을 켠 뒤, `시작.cmd`를 켭니다. 그다음 터미널을 열고 시험 폴더로 갑니다.

```bash
cd game\bridge
```

**사고 한 번 내기** (도시 맵 시내에서 세워 둔 차를 들이받습니다)

```bash
python crash_test.py --straight --gap 18
```

**여러 사고를 한꺼번에 내기** (위치 하나에 약 10분 걸립니다)

```bash
python crash_suite.py --spots skidpadSpawn
```

결과는 `game\bridge\runs` 폴더의 `suite_` 파일에 남습니다. 앱은 실제 차와 같은 경로로 들어오는 값만 받고, 게임의 정답 값은 끝난 뒤 PC에서 채점할 때만 씁니다.

## 게임 없이 사고 화면만 보기

에뮬레이터를 켜고, 앱을 설치해 한 번 열어 동의한 뒤(기록 서비스가 돌아야 함) 터미널에서 실행합니다. 사고 신호만 보내서 재현에 움직임은 없습니다.

```bash
<드라이브>:\askthecar-tools\sdk\platform-tools\adb.exe -s emulator-5554 shell am broadcast --user 10 -a com.askthecar.TEST_CRASH -n com.askthecar/.SimReceiver
```
